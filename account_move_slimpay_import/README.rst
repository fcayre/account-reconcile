This module will import your slimpay statements (called report in their
Web UI) as account moves before the reconciliation.

Slimpay API does not make it possible to import these reports
automatically so you will have to download them manually in the CSV
format and upload them to Odoo.

Configuration
=============

To configure this module, you need to create a new journal for
importing the payments:

#. Go to Accounting > Configuration > Accounting > Journals


.. figure:: https://raw.githubusercontent.com/OCA/account-reconcile/12.0/account_move_slimpay_import/static/description/create_journal.png
   :alt: .
   :width: 600 px

Usage
=====

To use this module, you need to:

#. Go to Accounting > Adviser > Import Batch File


.. figure:: https://raw.githubusercontent.com/OCA/account-reconcile/12.0/account_move_slimpay_import/static/description/import_move.png
   :alt: .
   :width: 600 px

#. Upload your slimpay report

   Note you can upload overlapping reports;
   your account moves will not be created twice.
